## 本次更新（v1.2.0）

### 判定区

* 感谢Fesutora的新视频提供相应的灵感和模板。新增「哑铃式」判定点：上下圆点 + 细杆 + 随 Beat 上下滑动的长条；长条在 Beat 到达判定区的瞬间落到最低点
* 三种命中反馈（按音符类型指定，也可按尺寸自动建议）：
  * **A 浅下沉**：命中瞬间两侧圆点膨胀
  * **B 深下沉**：命中瞬间整体放大 + 抖动
  * **C 微下沉**：只轻轻下压，除胶囊轻微膨胀外没有其他特效
* 膨胀 / 放大 / 抖动都改为"命中那一帧最大、之前渐大、之后渐小"，三个动画时长各自可调
* 胶囊运动可设缓动：不缓入缓出 / 仅最高点 / 两端都缓，强度可调
* 判定点与胶囊的颜色、描边（颜色 / 宽度 / 透明度）可自由设置
* 新增横向中轴线（基础设置，两种判定区样式都生效）
* 判定点后流速（1~8×）：过了判定点的音符可加速离场
* 没有 Beat 时判定区平滑过渡到静止位，不再空转往复

### 判定区分段

* 可按时间分段，每段使用各自的整套判定区配置（例如前半段普通、后半段哑铃）
* 段间淡入淡出可开关、可调时长，作用对象三选一：仅判定区 / + 横向轴线 / + 音符
* 分段与每段配置可导出 / 读取为 JSON 配置文件

### 文字与统计

* 新增独立「文字与统计」分区
* 角落水印：内容、位置、字号、颜色、透明度
* Beats 计数：已命中数或按 BPM 的拍号、字号 / 颜色 / 透明度、X/Y 精确位置
* Beats 统计分段：可按时段切分，显示"仅总 / 仅当前段 / 当前段 // 总"
* 可选在数值前显示 `Phase N` 段落号
* 可视化进度条：尺寸、位置、圆角、透明度、填充色、边框（宽度 / 颜色 / 透明度），
  进度依据四选一（时间 / Beats / 段内时间 / 段内 Beats）

### 其它

* 实装 `Ctrl+C` / `Ctrl+V`（复制 / 粘贴音符）
* 条带尺寸（画布）与内容尺寸解耦：改画布高度不再连带放大 Beat 和文字，内容大小由「内容缩放」控制
* 导出前会先检查输出位置是否可写，权限问题立即提示而不是渲染完才失败
* `Start.bat` / 安装脚本 / 打包脚本优先使用项目内 `.venv`
* 新增 8 套自动化测试（`devtools/`），覆盖快捷键、渲染参数、哑铃判定点、分段、统计、导出权限

> macOS 版需要在 Mac 上执行 `./build_app.sh` 生成；Windows 安装包见下方附件。

## v1.1

* 支持 macOS / Windows 双平台：新增 macOS .app 打包脚本、平台相关的 ffmpeg 查找、配置目录和更新附件选择
* 命中效果：普通音符命中瞬间开始 90° 旋转渐变到残影；长条头命中后固定在判定点，身体缩短到零才消失

* 命中后残影新增三角形、星形、十字、六边形等形状
