## 下载与安装

1. 下载下面的 zip，**解压到一个固定目录**（别在压缩包里直接双击）
2. 双击 `节奏条工作室.exe`

> **记得装 FFmpeg ！！！！！！！**　导出视频/解码音频都要用。
> 已经装过的会自动找到；没装的去 <https://www.gyan.dev/ffmpeg/builds/> 下
> `ffmpeg-release-essentials.zip`，解压后在软件「设置」标签里填 `ffmpeg.exe` 的路径。

## 本次更新（v0.991）

* 菜单栏顶上多了独立的 **检查更新**（`Ctrl+U`），启动时也会自动查一次（6 小时内不重复）
* 更新检查先问 GitHub API，**被限流（403）时自动改走 `releases.atom`**，不会再直接报错；
  两条路都不通时可以直接点「打开 Releases 页面」
* 复制粘贴改成**落在鼠标位置**，并且**支持跨音符种类**（粘到哪一行就是哪一种）
* 中间那枚 45° 菱形判定点**常驻显示**，音符打到它时按该音符颜色闪一下
* 区间批量填充音符（固定间隔 / 按节拍 / 交替类型）
* 参考视频对照：胶片条 + 视频自带声音当工作音频 + 频谱对音
* 界面语言：中文 / 日本語 / English，菜单栏最右边切换，即时生效
* 修掉一个退出时会弹「程序已停止工作」的问题（音频线程没在关窗口时收掉）

## 说明

* 打包成 exe 后首次启动会慢几秒（要解压运行库），之后正常
* 导出：节奏条默认 `1920×120` 透明视频，剪映推荐 MOV(qtrle)，PR/AE/达芬奇推荐 ProRes 4444
* 半透明即可，叠在原视频上层不会挡住原画面
