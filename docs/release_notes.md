## 本次更新（v1.1）

* 支持 macOS / Windows 双平台：新增 macOS .app 打包脚本、平台相关的 ffmpeg 查找、配置目录和更新附件选择
* 命中效果：普通音符命中瞬间开始 90° 旋转渐变到残影；长条头命中后固定在判定点，身体缩短到零才消失
* 皮肤自定义：判定点和每种音符类型可切换 8 种形状，或导入自己的图片；支持自由矩形裁剪、中心锚点
* 图片皮肤按原始比例绘制，最长边上限 1024px；图片缺失时自动回退到所选形状
* 命中后残影新增三角形、星形、十字、六边形等形状

> macOS 版需要在 Mac 上执行 `./build_app.sh` 生成；Windows 安装包见下方附件。
