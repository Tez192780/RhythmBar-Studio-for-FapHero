リズムバー・スタジオ · RhythmBar Studio
動画の音ハメ用リズムバー（音ゲー打音バー）エディター：中央に判定点、ノーツが両側から判定線へ流れ、
リアルタイム編集、任意のBPM変速、背景透過動画を書き出して、あなたの動画にそのまま重ねられます。

https://docs/screenshot.png

30秒で開始
启动.bat をダブルクリック（初回は依存関係を自動インストール）

音声または動画をウィンドウにドラッグ（動画は映像を抽出＋その音声トラックで音ハメ。複数セグメント連続インポート可）

スペースで再生、音楽に合わせてFで打音 —— または「BPM自動検出」＋「ノーツ自動配置」

タイムラインで微調整、右パネルで外観調整

Ctrl+Eで透過動画を書き出し、編集ソフトにドラッグして元動画の上層に配置

音声なしでも遊べます：ファイル → サンプルプロジェクトを読み込む。

コア機能
マルチセグメントメディア（音声／動画を自由に連結）
音声と動画をセグメントごとにインポートでき、毎回確認されます：末尾に追加／再生ヘッドに挿入／すべて置換

各音声はミックスに参加：波形、スペクトラム、BPM自動検出、アタック配置、再生はすべて連結されたタイムライン全体に基づく

動画クリップはタイムライン上でフィルムストリップ付きブロックとして表示（音声クリップは単色ブロック＋ファイル名）

参考映像は再生ヘッドに追従してクリップを自動切替；「カット切替で配置」はすべての動画クリップを一括スキャン

クリップ位置はプロジェクトと共に保存され、次回起動時に自動デコード復元（ファイルが見つからない場合はスキップ通知）

編集（音ゲー譜面エディターのように）
3つのマウスモード、ツールバーボタン／V／B／R／Tabで切替：

選択ドラッグ（V、デフォルト）	ノーツ配置（B）	範囲選択（R）
空白をクリック	選択解除	現在行にノーツ追加	—
空白をドラッグ	ノーツを範囲選択	グリッドに沿って連続配置（全体を一度にUndo）	時間範囲を選択
ノーツをドラッグ	移動	移動	—
ホバー後ハンドルをドラッグ	長押し（hold）に伸ばす	長押しに伸ばす	—
ルーラー／波形／スペクトラム／フィルムストリップ領域：

直接ドラッグ = 再生ヘッド移動（自由配置、スナップなし）——従来の操作感

Shift+ドラッグ = 時間範囲選択（Rモードに切替えてドラッグと同等）

範囲はハイライト表示され長さを表示、右クリック →「この範囲にノーツを配置…」/「範囲をループ区間に設定」/「クリア」

ループ区間は図上に「ループ x.xxs」と表示；解除方法：「ループ」チェックを外す、再生メニュー →「ループ解除」、
または右クリック →「ループ区間をクリア」

判定点（中央の菱形）
常時45°の灰白菱形を表示、ノーツの有無に関わらず常に表示

ノーツが命中した瞬間、そのノーツの色で一瞬染まる、同時に拡大＋拡散リング、その後スムーズに灰白へ戻る

調整可能：菱形の色／サイズ、染色強度、染色時間、判定ウィンドウ、BPMパルス、命中拡散リング

BPM変速
BPMセグメントリスト：任意数の変速セグメント、テーブルで直接時間とBPMを編集；タイムライン上でセグメント境界をドラッグして移動

Tap測速：数回クリックでBPM自動算出

BPM自動検出：音声を分析して推奨値＋ビートオフセット（beat 0の位置）を提示

ビートオフセット：波形がグリッドと合わない時、ワンクリックで「再生ヘッドを取得」して整列

ノーツは絶対ミリ秒で保存、BPM変更はグリッドのみに影響し、合わせたノーツは動かない

一括配置（3つの方法）
範囲選択 → 配置（推奨）：Shift+ドラッグ（またはRモード）で範囲を囲む →
右クリック「この範囲にノーツを配置…」、間隔を選択（ビート基準：1/4拍ごと、2拍ごと… /
ミリ秒基準：125msごと…）とタイプ；2タイプ自動交互も可、生成数をリアルタイム表示

自動配置 · 音声アタック：スペクトラルフラックスアタック検出、感度/最小間隔/グリッドスナップ調整可、
先に「テスト検出」で数を確認してから生成

自動配置 · 動画カット切替：映像のハードカットで自動打音

参考動画照合（音声付きでも使用可）
Ctrl+Shift+V（またはファイルメニュー）でmp4/mov/mkv/avi/webm等の参考動画をインポート

動画内の音声を自動的に作業音声として使用 —— 波形、スペクトラム、BPM自動検出、アタック配置すべてがそれに基づく、
別途音声ファイルを探す必要なし（既に他の音声を読み込んでいる場合は確認されます）

タイムラインは下から上へ：ノーツ行 → 動画フィルムストリップ → スペクトラム → 波形

左下の参考映像は再生ヘッドに追従；一時停止後は自動で精密フレームを取得（キャッシュ付き、ドラッグも滑らか）

「自動配置 → 基準：動画カット切替」で映像ハードカット点を直接ノーツに変換

動画パスはプロジェクトと共に保存、次回起動時に自動復元

スペクトラム（音ハメ主力）
タイムライン上のスペクトラム図：楽曲全体の対数周波数×時間マップ、ドラム/アタックは縦縞、
ビートグリッド線を縦縞に合わせればOK；左側に100 / 1k / 10k Hz目盛り

リアルタイムスペクトラムバー：下部に56セグメントのスペクトラム、再生時にリアルタイムで跳ねる（低域が左）

表示メニューで「タイムラインにスペクトラム表示」「リアルタイムスペクトラムバー」を個別に切替可

スペクトラムはバックグラウンドスレッドで計算（1曲約1秒）、完了後に自動表示、UIは固まらない

外観（自由配色、5プリセット内蔵）
ベースプレート：色、不透明度（低いほど元動画を遮らない）、上部明度上げ、下部暗度下げ、角丸、内縮、エッジハイライト、外影

判定点：常時菱形（色/サイズ）、命中染色（強度/時間）、縦線、判定ウィンドウ、BPMパルス、拡散リング

命中後残像：参考画像の「灰ブロック」を再現、遅延時間と消失時間を設定可、元スタイルフェードアウトまたは非表示も選択可

ノーツタイプ：自由に追加削除、各タイプに形状（菱形/ブロック/円/長押し）、色、枠線、サイズ、外発光を設定

プリセット：図中スタイル（暖灰半透明）/ ミニマル·ベースなし / ネオン発光 / ダークガラス / 純白ライト

リズムバーパラメータ
流向（右→左 / 左→右 / 両側から中央へ収束）、流速（全行程の秒数）、判定点位置、
ノーツサイズ、複数行展開、ビート目盛り、背景（透明 / 黒 / 白 / カスタム）。

書き出し
形式	透過	説明
MOV · ProRes 4444	✅	PR / AE / DaVinci 最も安定
MOV · QuickTime アニメーション (qtrle)	✅	剪映等の互換性良好、単色図形は容量小 —— まずこれを推奨
WebM · VP9 alpha	✅	容量最小、Chrome及び一部編集ソフト対応
WebM · VP8 alpha	✅	より古いデコーダーに対応
PNGシーケンス	✅	最も確実、「シーケンスインポート」と併用
MP4 · 黒背景	❌	編集でブレンドモードを「スクリーン / 比較(明)」にすれば黒背景除去可
サイズプリセット 1920×120（バー）/ 2560×160 / 1280×80 / 3840×240 / 1920×1080、カスタムも可

フレームレート、1~3× スーパーサンプリングアンチエイリアス、品質レベル、時間範囲（全体 / ノーツ範囲 / カスタム）

書き出しには進捗、残り時間予測、キャンセルボタンあり；「現在フレームをPNG書き出し」で素早く確認も可

インターフェース言語（中文 / 日本語 / English）
メニューバー右端の言語 / Language / 言語で切替、即時反映、選択は設定に保存され次回起動時も同じ言語。

静的テキスト（メニュー、ボタン、ラベル、ドロップダウン項目、テーブルヘッダー）はtranslate_tree()がコントロールツリーを走査して置換、
各コントロールの初回翻訳時に中文原文をQtプロパティ_zhに記録、以降の切替は原文から再翻訳

キャンバスに直接描画されるテキスト（タイムラインヒント、ステータスバー、プレビュー説明）は呼び出し箇所でtr() / trf()

ノーツタイプ名はあなた自身のデータであり、翻訳されません

新しいUIテキスト追加時は、中文原文をrbar/i18n.pyの_TABLEに追加（keyは中文原文）

動作環境
Windows 10 / 11

Python 3.10+（インストール時「Add to PATH」にチェック）

ffmpeg（書き出しと音声デコードに必要）
インストール済みなら自動使用；未インストールの場合、ソフトの「設定」タブでffmpeg.exeパスを手動指定も可。
ダウンロード：https://www.gyan.dev/ffmpeg/builds/

依存関係は2つのみ：PySide6、numpy。

text
python -m pip install -r requirements.txt
python main.py
単一ファイルexeにパッケージ化したい場合：build_exe.batをダブルクリック（pyinstallerインストールにネット接続必要、成果物はdist/）。
